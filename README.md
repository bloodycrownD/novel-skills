# novel-skills

小说创作技能库：5 个技能（含 1 个族入口）＋公共参考与项目模板。目录与用法详见《小说助手》。

| 技能 | 一句话定位 |
|---|---|
| 小说助手 | 族入口与公共知识库：家族地图＋reference（助手派遣·常见AI文风·常见小说文风·情色场景·创作规范模板） |
| 大纲生成 | 交底闸门：作者意图 → 段大纲 `故事大纲/00x-00y-zzz.md`（手动档先复述校验／自动档直接落档标推定） |
| 大纲循环 | 段大纲结构审查循环：七维度只读审，改到段大纲-ready，过堂戳落档 |
| 文章撰写 | 一步演出：开章、逐段实演（写作智能体优先）、归档、无题草稿、收尾成章、章状态落盘 |
| 文章循环 | 正文验货回修循环：三线（逻辑／文风／AI 腔）＋选择性深度＋章末全量，改到段-ready／章-ready |

## 分层约定

- **通用层**（本库）：换书不改——工作流技能＋小说助手公共参考。
- **项目层**（创作规范文件）：把 `小说助手/reference/创作规范-模板.md` 复制到小说项目工作区根目录（默认名 `创作规范.md`）按作品填写；技能从中读取，未提供时向作者询问，不虚构。
- **reference 归属**：技能专属的审查细则放该技能自己的 reference/；跨技能通用常识放《小说助手》reference/。

## 维护规程（防补丁漂移）

本库曾因「哪里翻车就在哪里加一条」式生长出现过协议矛盾（双线／三线打架、角色异名、条款重复五份）。为防复发，遵守：

1. **共享协议只改权威文件**，其余技能靠引用——发现某条款在第二个文件出现，即收敛回权威文件。
2. **同一规则在单个技能内只说一次**——重复是「模型不听话→加密度」的应急补丁，应回头改结构，不靠复制粘贴。
3. **改名／改口径全家 grep 自查**（含 reference/ 目录）：
   ```powershell
   Get-ChildItem -Recurse -Filter *.md | Select-String "旧名"
   ```
4. **新增红线先分层**：通用进对应技能或公共参考，项目实体进创作规范文件模板的示例位。
5. **description 只做路由**（触发时机＋一句定位），机制不进 description——技能列表每轮都付上下文税。
6. 每个技能末尾维护**执行检查清单**；循环类技能必须定义**终止条件与产出**；删除技能/参考时同步清理全部引用。

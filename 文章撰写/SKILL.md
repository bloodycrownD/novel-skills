# 文章撰写

章节不是写出来的，是演出来的。一次性生成整章是「非助手形状」的任务——全局品味没有局部奖励信号；一段一演把创作还原成一轮轮标准助手回合：**用户划边界，助手接好眼前这一球**。成章只是组装。

「撰写」不是照单施工：**骨架由大纲定，血肉由子代理在骨架里长出来。** 本技能一步出稿——审查与回修是《文章循环》的职责，不在段循环里做。

## 〇、作品文件只放正文

**章节文件是作品，不是工作日志。** 里面只允许三类东西：front matter（按第三节·5 规范）、段标题与场景转换分割线、正文。

**禁止入章节文件**：场景卡、用户引导原话、授权与裁定记录、审查报告与质检注、待办清单、进度摘要、讨论批注、`（待续）` 之类场记标记——一律不落档，用完即弃。留痕丢了不心疼，作品脏了才心疼。

自检口诀：**翻章节文件时，除了故事，不该看见第二个人的声音。**

工作档案（段进度、豁免、回修结论）有自己的家——章状态文件（第一节·4），与章节文件严格分离。

## 一、核心模型

1. **段**：执行的最小控制单元，**一段＝一份段大纲**（`故事大纲/00x-00y-zzz.md`，《大纲生成》落档）。每段＝起点（对手输入或场景推进）＋生成（助手）＋边界（用户喊停的位置）。**一段不等于一章**：一段可能占满整章，也可能只是章的一部分——分几段由用户定，与章节边界无关，别擅自假设。
2. **授权滑杆**：用户对每段内部的授权程度，逐段可调——

| 档位 | 用户给什么 | 助手干什么 |
|---|---|---|
| 逐句档 | 一字不差的台词 | 只演对方的反应与内心 |
| 骨架档 | 动作骨架（A→B→C） | 补全过程、措辞与血肉 |
| 方向档 | 只给意图（「这段从拘谨到忘形」） | 自行设计整段，用户留否决权 |

3. **控制权跟角色走**：用户可执任意角色。被执角色是用户的手（其台词具圣旨资格，零改动）；未被执行的角色才是助手的戏。同一段内可混合（用户执关键一句，助手补其余）。**圣旨资格的完整判定见《大纲生成》二·1**（「一字不改」标注／作者执角，两者取其一）。
4. **章状态文件**：工作区根 `章状态.md`（或创作规范文件指定路径）。每章一节，记录：草稿档路径、段进度表（每段：已归档／已过审）、**作者豁免记录**（段号、豁免的线、原话）、回修结论摘要、《文章循环》放行结论。会话中断后靠它恢复——不重审已豁免的线、不丢已拍板的裁定。它是工作档案，永不进章节文件。

## 二、工位分工

| 工位 | 谁 | 职责 |
|---|---|---|
| 导演兼主角 | 用户 | 执台词、定段边界、裁定基调与争议 |
| 演员 | 扮演助手 | 单点反应试演（见《小说助手》reference·助手派遣班底） |
| 执笔 | **写作智能体**（项目配置；无则通用智能体） | 长段补全、场景推进、心理铺陈、声口裁定、成章整理；**只输出不落库** |
| 场记兼制片 | 主代理 | 正文归档（只写正文）、派单喂料、设定层质检（不评文笔）、落库与清理、章状态维护 |

## 三、全流程

### 1. 开章

按创作规范文件的路径约定建章节草稿档（`00X-无题.md`，标题收尾时才定，见第四节）。档内**只有 front matter 占位**——开卷即干净，不要先把场景卡写进去再想着以后删。

一章无论分几段演，草稿档始终是同一份，攒到收尾才成章——**成章只在章末做一次**（见 3.4）。

### 2. 逐段循环

1. 交底：作者给意图，《大纲生成》（手动或自动档）落段大纲；需要结构核验时走《大纲循环》，放行后进入撰写。
2. 收用户引导（台词／动作骨架／方向意图），按第四节规格派单（生成正文）。
3. 回流后做**设定层质检**：圣旨台词零改动？称呼合规？知情边界？身体连续性？发现疑点（如底牌是否亮过头）**列给用户裁定，不擅自改**；质检结论不进章节档。
4. 归档正文：`## 段N · 标题`＋正文，段间以 `＊＊＊＊＊＊＊＊＊＊＊＊` 分隔（同场连续的段收尾时再决定去留，见 3.4）。
5. 更新章状态（段进度）。
6. **验货不在本循环**——段后按需或章末收尾，走《文章循环》；作者说「审一下这段」也是《文章循环》。
7. 若这一段是本章最后一段，等作者确认收尾后走 3.4 成章。

### 3. 中途裁定（可选质检）

声口或基调疑点（如「吐槽该不该出现在这一段」）→ 派写作智能体评估，要求产出「补／不补＋论证＋可直接采用的拟稿」。裁定结果收尾时遵它行事；**不得写进章节档**。

### 4. 收尾成章（每章一次）

**触发**：本章最后一段落定，且《文章循环》章末全量质检通过（或作者明确豁免），作者确认收尾。

**一段即章（短路径）**——本章只有一段：定标题、补摘要、对齐 front matter，完了。不缝合转场、不删脚手架、不新写开场段，也不许顺手替它补一段没演过的情节。

**一章多段（全套）**——

1. **派写作智能体整理**：既有正文原样保留、圣旨台词一字不改；新写开场段（把未成文的信息落成正文）；缝合段间转场；章末收束**不留钩子**（停在用户定的最后一段余韵处，别替下一章写开场）；拟标题（主选＋备选）；front matter 对齐本线既有章节格式。
2. **去回落脚手架**：删掉全部 `## 段N · 标题`；段间分割线按场景转换取舍——真的换场就留一条（与本线既有章节的用法一致），同场连续处删除；章节标题行统一为本线制式。
3. **主代理落库**：对话引号制式统一、复用词、圣旨台词逐一核对 → 写入标题档（`00X-标题.md`）。
4. 删除草稿档；章状态记「成章」。

### 5. front matter 字段规范

| 字段 | 草稿档 | 成章档 |
|---|---|---|
| **title** | 「无题」占位 | 收尾时定名（主选＋备选），双引号包裹 |
| **abstract** | 留空或一行占位 | 叙述体终稿：两到三段覆盖全章内容，**不剧透下一章** |

- abstract 用 YAML 多行块（`|`），段落间空一行；写故事发生了什么，不写「本章要表达什么」的评论腔。
- 线内既有章节若有其他自定义字段，沿用惯例；不发明无来源的新字段。
- 字段格式细则与自定义字段登记位：见创作规范文件「章节文件格式」节。

## 四、「无题」规则（标题与摘要不抢跑）

**草稿期一律 `00X-无题.md`：title＝「无题」，abstract 留空。**

- **为什么**：一段不等于一章，大纲长度事前不定——段间拟标题、写摘要，等于给没写完的东西盖棺；中途的「章意」常被后段推翻。
- **收尾确认时才补全**：作者确认收尾、章末质检通过后，整理派单一并产出标题（主选＋备选）与摘要，作者拍板，改名落库。
- 中途作者要试拟标题：可以给，但只留在对话与章状态，**不改文件名、不写 front matter**。

## 五、派单规格（固定六段）

1. **【任务】**：演谁／写什么／停在哪。扮演任务必须卡死「写到把回合交出去为止，绝不写对方角色接下来说的话或做的动作」。
2. **【必读文件】**：按《小说助手》reference·助手派遣五要素·4 送达（附件全文，路径降级者并行 read 补齐）。清单四类配齐：角色卡、本章草稿、本线近章（语感基准）、对口的前作／设定章节（创伤账／声口来源），外加本段段大纲。
3. **【场景卡】**：时间地点、前情、各角色当前状态——**含身体连续性账**（上一段立的生理状态要在派单里重申）。
4. **【起点输入】**：用户执的部分，台词原句照用并标注圣旨资格。
5. **【本段任务】**：顺序固定，逐条编号。
6. **【硬红线】**：称呼体系（按创作规范文件的演化刻度）；知情边界（角色只知道该知道的，不未卜先知）；不替用户角色说话；场景内正文、不总结不出戏；篇幅区间；随派单附《小说助手》reference·常见AI文风（九类病灶）与创作规范文件作文风红线。

**派单对象**：创作规范文件登记了**写作智能体**则优先派它（它自带小说写作能力，材料照常给足）；没有则派**通用智能体**——此时派单材料加倍写足：角色卡全文、声口与文风要点（常见小说文风＋项目语感基准）、基准章节一并随附，别假设它懂。

## 六、两个子代理怎么选（撰写侧）

| 场景 | 派谁 |
|---|---|
| 单点反应（她的反应是什么形状）、抉择试演、多轮对推 | 扮演助手（100-300 字） |
| 长段补全（亲密戏／动作过程）、场景推进、心理铺陈 | 写作智能体（无则通用智能体） |
| 声口评估与拟稿咨询、成章整理 | 写作智能体 |

班底定义见《小说助手》reference·助手派遣；审查类派遣（三线）见《文章循环》。写作智能体输出永不落库，文件操作归主代理。

## 七、踩过的坑（红线）

1. 扮演任务不卡「交回合」边界，演员就会抢导演的戏。
2. 知情边界双向都要守：角色不未卜先知未来剧情；对手角色不越权知道角色内心的底牌。
3. 声部分层：机锋与幽默只在角色防御完整、有距离或独处时出现；高压段是硬扛与失语——别为声口统一而磨钝「防线半塌」的质感。
4. 成章不留钩子：不写下一场的晨光与敲门，忠实停在用户定的末段。
5. **章节文件里出现非正文文字＝事故**（场景卡、引导、裁定、质检注、待办、`（待续）`……）。
6. 段间分割线不是每段必留：同场连续的段，收尾时必须缝合掉，否则会把「一次夜谈」切成三截。
7. **别演完一段就成章**：半章被当整章去定标题、写摘要，等于给没写完的东西盖棺。
8. 豁免与裁定不落章状态＝白豁免：会话一断就丢。

## 八、适用边界

- **适合**：对话密集、心理密集、人物少的室内戏——攻防回合碎，每段都有反应可钓。
- **不适合**：大场面群戏、多线并进、时间跨度大的结构梳理——先做时序梳理，再把其中一格拆段来演。

## 执行检查清单

- [ ] 开章只建 front matter 占位；草稿档全章一份、title＝无题
- [ ] 每段：交底→引导→派单（六段规格）→设定层质检→归档→章状态更新——未在段内夹带审查
- [ ] 圣旨台词逐句比对零改动；未标圣旨的台词润色归写作智能体
- [ ] 派单对象正确：写作智能体优先；通用智能体时材料加倍写足
- [ ] 标题与摘要只在收尾确认后补全；中途不改文件名
- [ ] 收尾只在章末：短路径不添油加醋，多段路径去脚手架＋整理落库
- [ ] 章节文件里只有故事；工作档案全在章状态与对话
- [ ] 项目层事实（路径、称呼刻度、语感基准）取自创作规范文件

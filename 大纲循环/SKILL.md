# 大纲循环（结构审查）

大纲是规格，规格的毛病是结构性的：动机不成立、时间线打架、伏笔漏账、与既有正文咬合失败、红线漏标。本技能用子代理的冷眼把这些抓出来，改到干净，再交《文章撰写》。**只审结构，不审文风**——大纲按事件落笔，无文风可言；文风与 AI 腔是正文阶段的尺子。

## 一、什么时候用

- 作者要求审／校验某段大纲（「看看这份大纲有没有问题」「这段大纲靠谱吗」）。
- 复杂段落档后（人物多、背景重、跨章伏笔），建议走一轮再执行。
- 自动档落档后作者改动较多，想核验一遍。
- **不用**：简单段、作者明确豁免、或只要复述校验（《大纲生成》手动档已含复述闸门，不等于结构审查）。

## 二、循环

1. **派理性助手只读审**，七个维度：
   - **动机线**：每个转折有人物的利害支撑，无「剧情需要」式跳跃
   - **时间线**：与既有正文一致、本段内部自洽
   - **伏笔账**：埋的／收的／悬的与既有正文对得上
   - **知情边界**：谁知道什么自洽，无未卜先知
   - **与既有正文咬合**：无矛盾、无重复；称呼、状态、身体连续性延续
   - **事件栏纯净度**：只有事件（行为与事实），无评价／因果／心理／预告混入
   - **红线对照表完备性**：该标的行标了没；「本段重点」是否漏了本段最大风险、有没有越权新增走向
2. **派单照《小说助手》reference·助手派遣**：首诊不带预设与既往结论；复审只带条目做回归追踪，不带解读。
3. **汇总**：结构硬伤（红线级，pass/fail）与改进建议分开报；硬伤就地改档，建议主代理自判。
4. **走向类分歧不擅改**：大纲的最终真值是作者——把分歧两端列出来请拍板，不改完再问。
5. **复审**：修正后重派，只验上轮条目是否闭合（红线项走《小说助手》reference·助手派遣回修纪律：重派对应项快查）。
6. 出口判定见第三节「终止条件与产出」。

## 三、终止条件与产出

**段大纲-ready**（同时满足）：

- 七维度红线级发现＝0（结构硬伤全部改净）；
- 上轮条目复审全部闭合；
- 走向类分歧全部已请作者拍板；
- 作者放行。

**轮次与震荡**：循环上限 **3 轮**；同一问题震荡 ≥3 轮 → 停下，列两端请作者拍板——大纲的最终真值是作者。子代理失败／返回不合格：重派一次（修措辞不重发）→ 仍失败则主代理手工等效审查，标注「手工审查」（《小说助手》reference·助手派遣失败政策）。

**产出**：

| 产出 | 落点 |
|---|---|
| 修订后的段大纲（就地改；圣旨台词与已定设定不动） | `故事大纲/00x-00y-zzz.md` |
| 过堂戳（一行：过堂 N 轮 · 无结构硬伤 · 日期 · 作者放行） | 段大纲文件文首——执行者据此不重复核验 |
| 放行信号 | 交《文章撰写》进入实演 |

## 四、红线

1. **不审文风、不审辞藻**——那是《文章循环》正文验货阶段的尺子，与本循环无关。
2. **不越权改走向**：结构修正限于动机、时序、伏笔、咬合层；圣旨台词与「已定设定」不动。
3. **就地改档并报账**：每轮改了什么，一句话向作者报明；放行结论以过堂戳随段大纲文件走，已开章者补记章状态，不留在对话里。

## 执行检查清单

- [ ] 只派理性助手、只读审、七维度齐
- [ ] 首诊派单无私货；复审只带条目不带解读
- [ ] 硬伤／建议分开报；走向类分歧已请作者拍板
- [ ] 修正后已复审；终止条件四条齐（无硬伤／条目闭合／分歧已拍板／作者放行）
- [ ] 过堂戳已落段大纲文首；放行信号已交《文章撰写》
- [ ] 未审文风；未动圣旨台词与已定设定

# 小说助手（族入口 · 公共知识库）

小说创作家族的**目录页与公共书架**：族内技能管工作流（怎么一步步把一章写出来），本技能管三件事——**指路**（现在该用哪个技能）、**公共参考**（跨技能通用的知识）与**派单协议**（怎么派子代理）；后两者统一放本技能 reference，各技能引用不复制。

## 一、家族地图

```
大纲生成 ──→ 大纲循环 ──→ 文章撰写 ──→ 文章循环 ──→ 成章收尾
（演什么）  （结构核验）  （一步演出）  （验货回修）  （补题/摘要/落库）
                │                          ↑
                └── 放行后进入撰写 ─────────┘
助手派遣：以上任何环节要派子代理时的交通规则，协议在本技能 reference/助手派遣.md
```

| 用户在说 | 用哪个 |
|---|---|
| 「先说说你怎么理解这一段」「我来交底」 | 《大纲生成》手动档 |
| 「这段你自动写」「直接落档」 | 《大纲生成》自动档 |
| 「看看这份大纲有没有问题」 | 《大纲循环》 |
| 「按大纲演」「实演」「一段一段推」 | 《文章撰写》 |
| 「审一下这段正文」「这段写完了吗」 | 《文章循环》 |
| 要派任何子代理（审查/试演/分析/写正文） | 协议见本技能 `reference/助手派遣.md` |
| 「帮我写小说」但没说从哪步开始 | 先问清：在交底、在核验、在写、还是在审——再指路 |

## 二、公共参考（reference/）

**归属原则：技能专属的审查细则放该技能自己的 reference；跨技能通用的常识与协议放这里。**

| 文件 | 内容 | 谁在读 |
|---|---|---|
| `reference/助手派遣.md` | 派单协议（唯一权威）：五要素、三铁律、班底、返回契约、失败政策、轻量豁免 | 所有工作流技能派子代理时的交通规则 |
| `reference/常见AI文风.md` | 九类 AI 腔病灶（症状／成因／改法）、不可误伤边界、grep 词表 | 《文章循环》AI 腔线的尺子；《文章撰写》派单硬红线随附 |
| `reference/常见小说文风.md` | 通用中文小说文风要点（视角／声口／节奏／白描） | 《文章循环》文风线的通用底尺；《文章撰写》派单随附 |
| `reference/情色场景.md` | 情色题材规格：玩法序列化、发情体感、红线、辞藻表 | 情色主干段的生成／撰写／审查三方共用 |
| `reference/创作规范-模板.md` | 项目层事实接口（模板） | 接入新作品时复制填写（见下） |

## 三、项目接入（换一本书只改这里）

1. 复制 `reference/创作规范-模板.md` 到小说项目工作区根目录，命名 `创作规范.md`，按作品填写。
2. 族内技能凡需要项目层事实（语感基准、语域分层、路径约定、称呼刻度、暗线、禁忌、量制），一律从该文件读取；未提供时**向作者询问，不虚构**。
3. 若项目配置了**写作智能体**（写正文用的专用 agent），在创作规范文件「写作智能体」栏登记名字——《文章撰写》派单时优先用它，没有则用通用智能体并加倍写足派单材料。

## 四、分层原则（一句话版）

- **通用层**（本库）：换书不改——工作流技能 + 公共参考。
- **项目层**（创作规范文件）：每本书一份——事实与口径。
- 冲突时项目层优先；通用参考是底尺，不是最终裁判——真值在基准章与作者。

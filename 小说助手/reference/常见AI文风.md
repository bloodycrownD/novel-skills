# 常见 AI 文风（九类病灶 · 通用尺子）

> 管的是「一个活人会不会这样开口，一个作者会不会这样落笔」——与题材、语种、世界观无关，所以通用。
>
> 具体项目的文风基准（语域分层、专有词域、辞藻禁忌、度量与币制）属于项目层，另见创作规范文件；本尺子只管通用病灶。两者不冲突时并用，冲突时项目层优先。
>
> **使用方**：《文章循环》AI 腔线以此为尺；《文章撰写》派单时作为通用硬红线随附。

## 唯一的判断标尺

**一个活人会不会这样开口，原作会不会这样落笔。**

- 台词：像人在那个处境里说的话，不像发言提纲，不像总结陈词。
- 旁白：按目标作品既有文本的节奏与句法铺开，而不按「好读、简洁、有金句」的现代写作习惯铺开。

**基准从材料里来，不从「顺滑」里来。** 目标作品若是译制体、古典白话、冷硬白描或别的什么质地，那么「读起来不那么顺、有点隔膜」可能正是它的本色，抹平它就是失真。动笔前先把基准文本读进去，别凭手感。

**顺畅本身可能就是失真的来源**：越顺滑、越成词、越像母语随笔，越可能已经离基准远了。基准偏生硬质地者，宁可略生硬，不可太顺滑。

## 九类病灶

### 1. 压缩体

**症状**：三五字独立成段充当心理节拍（「太顺了。」）；名词短语充当主语或话题（「这一手」「这笔账」「这三桩事」）；极短字数抛出一个判断、结论或总结（「这一笔，他比谁都会算。」）；用短语代替完整句子下指令。

**成因**：不是人物在想事，是作者在打标题。以文字密度优先于人的真实说话，取信息之「省」，失人物之「活」。

**改法**：把动作、状态与因果写足，铺成完整长句；让判断落回叙述里，而不是被单独拎出来示众。旁白按基准文本的节奏铺陈，独词成段一般不成立。

### 2. 生理套话流水线

**症状**：任何情绪都配同一个体表信号——泛青／泛白、咬唇见血、口中血腥味、眼眶发热、热意打转、喉头滚动发紧、睫毛颤动、胸口起伏、指节收紧、掐进掌心、身子绷紧、倒吸冷气、心跳如鼓。

**成因**：用公式化信号顶替情绪。信号本身没错，错在通用——任何情绪都走这条流水线。

**改法**：先做减法，能删的信号直接删，留白优先；要写的须从当前场景取物取声（烛芯、门缝的光、器物的声响、衣料摩擦、窗外的风），写成具体而不通用的动作。**病灶不在「写了身体」，在「任何情绪配同一套信号」。**

### 3. 声口失真

**症状**：受害、受制、慌乱或失态者的台词，呈现出分析式的条理与完整的心理复盘、人生履历式自白。字数够长而气不对，同属此列。

**改法**：以迟疑、打断、半句话、突转而止、避重就轻去写。人在那种处境里说不成一二三。

### 4. 说教腔

**症状**：借人物之口作现代观念阐释、因果讲演或人生总结；人物成了作者的传声筒。

**改法**：人物的世界观由身份、利害、所处阵营的话术决定，不由作者的观点决定。同样的道理，让处境与身体去体现，或干脆不体现。

### 5. 主体错位

**症状**：说话人以「我」为价值锚点——拿自身的兴致、挑战欲、选择权充当夸赞或表态的落点（「我就喜欢你这股倔劲」「我决定给你一个机会」）。

**改法**：夸人、下承诺、作判定时，话头落在对方身上。

### 6. 分镜稿段法

**症状**：一句一段、段末必收一个落点，通篇是「一句＋一句＋一句」的节拍体；画面切得清清楚楚，却读不出小说的呼吸。

**成因**：写的是剧本或分镜，不是小说段。

**改法**：小说段常三四句，以「而／于是／然后／接着／不过」衔接，对话可嵌在叙述段内，动作与说话连成一气。必要的短句（见「边界」）不受此限。

### 7. 替人物下判断

**症状**：旁白替人物总结情绪、报幕分层（「……之后，心底最先泛起的，却不是感激，而是……」）；旁白抢在人物前面把潜台词说破。

**改法**：把话让给台词、让给世界、让给身体；旁白至多在收尾替读者叹一句。留白优先——不点破、不评判，留给读者看。

### 8. 语域串层

**症状 A（身份层）**：不同身份、文化、阵营的人说同一种腔调；旁白书面语、市井粗话、受害者的破碎台词、外来的超然俯瞰腔混作一团。

**症状 B（词域层）**：渗入与世界观不符的词——方言、古典白话、市井话本词（腌臜、做派、江湖气之类）、现代流行语。

**改法**：按创作规范文件的语域分层表逐句核对属于哪一层。词域以基准文本为界，宁可生硬，不可串味。

### 9. 现代词与套路词

混在句子中间，通读易滑过，必须逐条扫。

| 类别 | 禁用（示例） | 替换方向 |
|---|---|---|
| 现代科学词 | 荷尔蒙、多巴胺、神经、基因、电击 | 体感白描 |
| 网络流行语／二次元调侃 | 破防、上头、傲娇、绷不住 | 删；按人物声口重写 |
| 现代泛称 | 这一方天地、造物、器具、卧房之中 | 具体名词（这间客房、那把椅子） |
| 网文男主特写套话 | 懒洋洋的笑、深邃的眼睛、玩味的笑意、意味深长、好看的眉眼、修长的手指 | 删；只写外部动作与语言，不作外貌特写 |
| 古典／评论词 | 居高临下、不绝如缕、四目相对、意味深长 | 具体动作（如：微微垂下眼帘） |
| 中式成语滥用 | 求之不得、四肢百骸、决堤、灭顶、语无伦次、不得其门而入、最后一丝清明 | 同义的质朴说法（难得、整个身躯、止不住、无比、颠三倒四） |
| 中文古典白话／话本词 | 腌臜、做派、江湖气、门道、讲究 | 按基准文本的词域替代 |
| 题材专用辞藻（如中式艳情词） | 花心、云雨、春风一度 | 见《小说助手》reference·情色场景的辞藻表，或创作规范文件 |
| 本土度量与器物 | 尺、寸、钟情于算盘之类 | 按世界观量制与器物名 |
| 生理套话 | 见第 2 条 | 从当前场景取物取声 |

## 边界（不可误伤）

**短本身不是罪。** 以下都不算病灶，不得以「治短句」为名一律拉长：

- 对答中的回声反问、咬合一拍的简短应答。
- 买卖、承诺、交付场合的套话短句（如「很好，成交。」）。
- 人物本就寡言、冷硬或地位悬殊，短台词正是他的声口。

**病灶在「用最少字数塞进一个结论」，不在字数多寡。**

其余几条同理：

- 情绪与生理反应该写时照写——受虐、情欲、伤病、疼痛本就是身体戏，禁的是通用化的注脚，不是身体本身。
- 旁白动情、旁白解释世界（教义、物种、战局、风土），在某些原作里是本色，可以保留；禁的是旁白替人物下心理判断。
- 冷硬、粗俗、笨拙的措辞若属于基准文本的质地，保留；要清的是不属于这份世界的腔调。

## 审查作业法（供《文章循环》AI 腔线用）

**分工**：词表与统计是机械检查，**主代理直接跑**（grep／数段落），结果作为材料随派单附上；病灶判断是密集判断，派 AI 腔线子代理。

1. **分段扫压缩体**：数一数段落的字数与句数，凡独词段、短语段，逐一问它是不是「被拎出来的结论」。
2. **grep 词表**：生理套话／现代词／套路词／本土度量四张表跑一遍，逐处定位（主代理跑）。
3. **比对基准文本**：段落平均长度、从句密度、对话是嵌在段内还是另起、标点习惯。基准是译制体的，看有没有被写顺手了。
4. **台词出声读**：凡读着像念稿、像总结、像作者心得的，改。
5. **交报告**：按《小说助手》reference·助手派遣返回契约——红线违反（词表命中属红线）与风格建议分开列，每条给原文定位＋病因归类＋可直接采用的修改拟稿（不是「建议加强」这类空话）。

# 创作规范（模板）

> **接入方式**：复制本模板到小说项目工作区根目录，命名 `创作规范.md`（或放入项目技能目录作为《创作规范》技能），按作品填写。族内技能以「创作规范文件」引用本文件。
> 未提供的栏，技能会向作者询问，不会虚构。下表「示例」列只是格式示意，不是内容建议。

| 节 | 写什么 | 示例 |
|---|---|---|
| 作品与路径 | 章节目录与命名制式、草稿档→成章档的路径约定、段大纲与 `章状态.md` 的位置 | `故事大纲/00x-00y-zzz.md`（段大纲）；`故事章节/00X-无题.md`（草稿）→ `00X-标题.md`（成章） |
| 写作智能体 | 项目配置的写正文智能体名；《文章撰写》派单优先用它 | 〈智能体名〉；没有则留空（用通用智能体） |
| 语感基准 | 普通章基准、情色章基准（各 1–2 章成文章节路径）；基准质地一句话 | 「基准偏译制体：宁可略生硬，不可太顺滑」 |
| 语域分层 | 这部作品有哪几层语域、各由哪些人物承担 | 「上层标价冷语／身份荣誉话术／外来者俯瞰腔」 |
| 称呼体系 | 称谓演化刻度在哪查、当前章节处于哪一刻度 | 称谓表文件路径，或逐章记录处 |
| 暗线与封存项 | 封存暗线清单——启用与否由作者定，技能不得主动牵出 | 〈暗线名、涉及角色〉 |
| 禁忌逐字 | 用户指定的硬边界，逐字执行，审查时专项核对 | 〈如「不以 X 入 Y」〉 |
| 量制与器物 | 度量、币制、器物口径；禁用的本土词 | 「长度用『比手指略长』式身体参照」 |
| 世界观口径 | 魔法／技术口径（如低魔：药剂商品化、不解释原理） | … |

## 章节文件格式（front matter）

章节文件（草稿 `00X-无题.md` → 成章 `00X-标题.md`）以 front matter 开头，字段固定两个＋自定义：

```yaml
---
title: "无题"       # 草稿期固定占位「无题」；收尾成章时才定名（主选＋备选，作者拍板）
abstract: |         # 章摘要：草稿期留空；成章时才补全
  （叙述体两到三段，覆盖全章内容，不剧透下一章；段落间空一行）
---
```

- `title`：成章前一律「无题」，不得抢跑（《文章撰写》无题规则）。
- `abstract`：成章时补全；写故事发生了什么，不写「本章要表达什么」的评论腔。
- **自定义字段**：本线既有章节若有其他字段，沿用惯例并登记在下一行，不发明无来源的新字段。

front matter 自定义字段（按作品登记）：〈无〉

## 正文制式（供成章核对）

- 草稿期：`## 段N · 标题`＋正文；段间以 `＊＊＊＊＊＊＊＊＊＊＊＊` 分隔。
- 成章时：去段标题脚手架；分割线按场景转换取舍（真换场留一条，同场连续删）；对话引号制式按本线惯例（〈登记：「」／""〉）。

# 助手派遣（派单协议 · 唯一权威）

> 本文件是「怎么派」的唯一事实来源：五要素、三铁律、班底、返回契约、失败政策都在这里定义；族内技能一律**引用本文件，不得另立拷贝**。派给哪个子代理由主对话按问题类型决定。三线审查拓扑（怎么组线、选择性深度）在《文章循环》定义。

## 一、什么时候用

- 用户要求审查、复审某个大纲／正文／设定文件，或做独立分析、评估、拟稿咨询。
- 创作流程走到需要派遣子代理的环节（大纲过堂、正文验货、设定核验、试演、成章整理……）。

## 二、班底

| 角色 | 长处 | 典型任务 |
|---|---|---|
| **理性助手** | 冷判、核对、考据 | 设定层分析与利害账、考据、逻辑线审查 |
| **写作助手** | 文字与声口 | 长段补全、场景推进、心理铺陈、成章整理；文风线与 AI 腔线审查 |
| **扮演助手** | 进入角色 | 单点反应试演：身体、神态、至多一句台词，停在交回合处 |

班底是按任务形状分的工位，不是三个人格；可按需增设角色，但**命名须全库一致**（历史上「感性助手／扮演助手」混用即此类漂移）。

## 三、派单五要素（缺一不可）

1. **明确对象**：哪个文件（完整路径）、什么类型（大纲／正文／设定）——大纲与正文审法不同，分别交代。
2. **任务步骤具体清晰**：先审什么、重点听哪里、按什么输出格式交卷——一步步写明白，不让助手自由发挥。
3. **必读文件清单**：逐个列出完整路径并注明用途——审查对象本体、角色声音／文风基准、设定依据都要给全；清单不明就是瞎审。
4. **送达方式**：必读文件随派单**以附件全文送达**，助手无需再 read，列清单只为标明哪份是什么用途。附件中只给到路径者（超出附件预算被降级），用 read **并行一次性**补齐——同一条消息并发全部 read，勿逐个顺序读；清单之外需参考的别的文件，助手自行以 read 取用。
5. **输出方式**：明确「在回复中直接输出报告，不写任何文件」；落盘与汇总由主对话完成。

## 四、三铁律

### 铁律一：每次调用都是新会话

- 每次派单对助手而言都是第一次见这份材料，它看不到任何历史会话——这恰恰是审查的价值所在。
- **禁止在派单里转述上一轮的审查结论、已修内容、轮次信息**（如「上轮你指出X、已按建议改成Y，请复核」）——这会让它带着预设找问题、只盯着旧账复核，丢掉发现新问题的能力。
- 复审也只说「请审查X」，材料里的变化它自己会发现。
- 区分「轮次信息」与「当前需求」：用户钦定项、尺度红线、本轮审查重点**可以给**（这是需求）；「根据上轮意见改了什么」**不给**（这是历史）。

### 铁律二：禁止夹带私货

**派单是提问，不是给答案。** 主代理不得把自己对材料的判断、结论、倾向、框架、预设的「正确答案」塞进派单——助手只会顺着靶子走、替预设盖章，独立视角当场失效。

| 类别 | 处置 |
|---|---|
| 用户的需求（钦定项、红线、本轮重点） | 给 |
| 主代理的预设与结论（私货：预设的张力点／结论候选／「我倾向」／自拟框架） | 不给 |
| 上一轮的修正与轮次信息（历史） | 不给 |

**自检口诀**：把派单读一遍，凡「主代理认为／建议／预设／我倾向……」「请重点看这几处（附自己的分层）」——**全删**。派单里只应剩下：任务、材料路径、格式要求、用户的钦定项。

### 铁律三：创作类派单的措辞隔离

**派单里的底账不是范文，是记帐。**

- 拟稿、写正文、写角色卡等创作类任务中，派单自带的大纲要点、事实底账、摘要只承担**事实层**功能，其行文风格与成品风格无关。
- 派单中必须明令：**完全自由创作，风格一律从必读基准文件（原著、成片章节）里来，禁止照搬提示词中的词语、短语与句式**——专有名词、既定事实、圣旨台词除外。
- 主代理收稿时逐句核对：成品里出现提示词原句／原短语而并非钦定项的，一律打回重写。
- 主代理自己写底账时同样自觉：用干瘪的记账白话写，不写漂亮话——从源头减少可被复用的措辞。

## 五、审查拓扑

三线怎么组（逻辑线／文风线／AI 腔线）、选择性深度、豁免落盘、章末全量——定义在《文章循环》第二节；大纲的结构审查循环见《大纲循环》。本协议只管运输：怎么派、怎么返回、失败了怎么办。

## 六、返回契约

### 审查类（统一骨架）

```text
1) 总评：一句
2) 红线违反：每条＝原文定位＋违反哪条＋可直接采用的拟改；无则写「无」
3) 风格建议：每条＝原文定位＋依据＋可直接采用的拟稿；无则写「无」
4) 亮点：简短
```

**红线项是 pass/fail 硬判定**：知情边界、称呼体系、不成伤、禁忌逐字、圣旨台词被改动、低魔口径、玩法序列缺项。**风格建议是材料**：质地、声口、节奏——哪条采纳、哪条不动，主代理自己判，不许照单全收（尤其 AI 腔线：短句、寡言、上位者的冷硬，看着像病灶，可能正是骨相）。**报告是材料，不是判决**——但红线不是材料，是闸门。

### 创作类（统一骨架）

```text
1) 成品本体（正文／拟稿）
2) 自报偏离：相对派单要求的任何偏离，逐条；无则写「无」
3) 需作者裁定项：如有
```

### 主代理解析规则

- 红线逐条**必须处置**：改正文，或列给作者裁定。
- 建议自行裁定；采纳的落正文后进入回修复审（见第七节）。

## 七、失败政策与回修纪律

- **子代理失败／返回不合格**：重派一次——修正派单措辞，不原样重发；仍失败则主代理手工等效完成，标注「手工审查／手工整理」。
- **回修后必须复审**：采纳的修改落正文后，主代理逐句比对修正处；**涉及红线项的回修，重派对应线快查**（只查该红线项是否闭合）。
- **同一问题震荡 ≥3 轮**：停下，把分歧两端列给作者拍板——真值在作者，不在循环。
- **段级回修循环上限 3 轮**：超出即停，报未决项请作者。

## 八、轻量豁免（什么时候不派）

派遣的价值 = 上下文隔离 ＋（审查的）独立视角或（生成的）并行。两者都不沾的活，主代理直接干：

- **机械检查永不派子代理**：词表 grep、称谓表核对、禁忌词扫描、段落统计——工具调用即出。
- 单文件短拟稿、格式对齐类小活，主代理直接做。
- 判断密集的层（声口、设定咬合、病灶判别）才值得出门。

## 九、派单模板

```text
请<审查/分析/评估/试演/拟稿> <文件路径>（<类型：大纲/正文/设定>），在回复中直接输出报告，**不写任何文件**。

<类型专属指引：大纲→结构/动机线/伏笔账/与既有正文咬合；正文→逐段过原则；设定→能否撑起预设剧情；试演→停在交回合处；分析→需覆盖的维度>

<本轮钦定背景/用户已拍板项——如有，原样列出并注明「审执行分寸，不审方向」>

必读文件（已随附件全文送达，无需再 read；下列清单只为标明用途）：
- <路径>（<用途：审查对象/声音基准/设定依据…>）
- …

（附件中只给到路径、未给正文者，用 read 并行一次性补齐；清单之外需参考别的文件，自行以 read 取用。）

按返回契约交卷：<审查类＝总评/红线违反/风格建议/亮点；创作类＝成品/自报偏离/需作者裁定项>。
```

> 模板里没有「主代理的看法」这一栏——那是私货，见铁律二。
>
> **创作类派单在此模板上另加一条**：完全自由创作，风格一律从必读基准文件里来，禁止照搬本提示词中的词语、短语与句式（专有名词、既定事实、圣旨台词除外）；主代理收稿时逐句核对，复用即打回。

## 执行检查清单

- [ ] 铁律一：未携带上轮结论与轮次信息（钦定项与红线除外）
- [ ] 铁律二：反锚定自检已过——派单里无私货
- [ ] 铁律三：创作类派单已加措辞隔离令
- [ ] 审查拓扑按《文章循环》；选择性深度有据（豁免落章状态）
- [ ] 返回按契约解析：红线必处置，建议自判
- [ ] 失败走重派→手工标注；回修后已复审；震荡≥3 已上报作者

# 情色场景（题材规格）

> 《大纲生成》管这一段演什么、《文章撰写》管怎么演、《文章循环》管验货；本规格管**情色这一类的具体血肉怎么填**——玩法怎么设计、发情怎么写真、红线怎么守、辞藻怎么不翻车。情色主干段的交底、派单、审查三方共用本文件。
>
> **适用**：情色／发情情节、调教／承欢段落——写大纲时设计玩法、写正文时落项、审查时逐项核对。

## 一、核心方法：玩法序列化

情色场景的骨架是**一串具体的玩法，按序演出**，不是「两人缠绵了一夜」这种概括。做法：交底时把玩法列成序列（逐条编号）→ 派单时逐项落文 → 审查时逐项核对。**不许删项、不许缩写成过场。**

序列模板（按演出顺序，可按段增减）：

1. **起势**——情欲刚起，主导方不急，先勾：只看不碰、命对方自陈（自己撩裙、自己分腿）、穴口打转就是不进。要点是把「想要」与「不敢」的拉扯写足。
2. **身位**——换着来。女上位、背身骑、后入、侧抱、抱起来……每个身位至少给一个**专属动作细节**（掐腰、拽链、架腿、托臀、按后脑），不能只换姿势不换写法。
3. **口与手**——口交（主导方控深浅）、舔遍、手指玩前面。
4. **部位专项**——如乳部（注射、吮、换边、轻磨）、后门（手指挑逗）。
5. **点缀**——蜜酒、饰品（颈链）、束缚（绸带）之类，调味用，可不选。
6. **收尾**——做一整夜 → 力竭 → 落到一个**关系性动作**上（如被抱在怀里睡）。收尾的动作往往才是这一段的落点。

**切段**：一份玩法序列可跨多段，按「起势→身位→口手→部位→点缀→收尾」切段，每段演一节，各自一份段大纲。别把整份序列塞进一段，否则玩法会被压成过场。

## 二、发情状态的写法

药／媚药／发情状态是情色的引擎，写法有三条铁律：

1. **只写体感，不写原理**。写发热、迷糊、轻飘、放松舒适、下体发痒、渴求；**禁**多巴胺、荷尔蒙、神经等现代科学词，**禁**解释药的来历与机理（口径按创作规范文件的世界观约定）。
2. **体感递进**。热 → 迷糊放松 → 下体痒与渴求 → 求 → 纵情 → 力竭，一条上行曲线，直到力竭才落。
3. **声口崩坏是重点**。平日克制、有分寸的人物，在药力下用她绝不会用的声调说话（撒娇、黏软、低贱淫荡）——**落差**就是戏。写出「说出口连她自己都陌生」。

**发情者唯一的恐惧不是疼痛，是「被拒绝、被吊着」**（想要而不得）。抓住这一点写。

**分寸的丢失**：药力＋整夜 → 平日不敢的放肆（如本该蜷在床沿的人，被搂在怀里睡）。写她不自知，**不点破、不评判**，留给读者看。

## 三、身份反差与主导方

- **张力来自落差**：身份越端、越有尊严的人物被拉进肉欲，崩坏时越有戏。
- **但不失人物**：崩坏的是声口与分寸，不是人格底色——她仍是那个务实、清醒的人，只是被药力泡软。
- **主导方保持超然**：从容、好色、手段随手使来；台词短、带挑弄；**不解释、不炫耀、不失控**（除非用户指定）。
- **镜头落在受方体感**：默认受方第一人称或贴身第三人称，感官落点在她的身体反应与生理失控上；创作规范文件另有指定则从之。

## 四、红线

1. **世界观口径**（低魔等约定按创作规范文件）：药走药剂学口径（明码标价的商品），不解释原理，不添新魔法体系；外来手段挂「药／炼金」口径。
2. **不成伤**：除非用户明确要伤害向，一切花样默认落在快感上——手指粗细不撕裂、束缚不勒痕、齿磨要轻、注射只写刺痛一下。
3. **禁忌逐字守**：用户指定的边界（如「不以阴茎入后庭」）逐字执行，审查时专项核对。
4. **知情边界**：视角人物不知道她不该知道的（身份底牌、他人的秘密）。
5. **原著语域分层**：按创作规范文件的语域分层表，不串层。

## 五、辞藻纪律（本类最容易翻车处）

情色场景是中式艳情词、古典成语、现代套话的重灾区，且这类词**混在句子中间**，通读易滑过，必须逐条对照扫。以下词域一律不得入文：

| 类别 | 禁用（示例） | 替换方向 |
|---|---|---|
| 中式艳情／古典词 | 花心、云雨、春风一度 | 穴心／最深处；直白白描 |
| 中式成语 | 求之不得、四肢百骸、决堤、欢天喜地、灭顶、语无伦次、不堪入耳、不得其门而入、最后一丝清明 | 难得、整个身躯、止不住、迫不及待、无比、颠三倒四、下贱放荡、只在外面蹭弄、最后一点理智 |
| 古典／评论词 | 居高临下 | 微微垂下眼帘 |
| 男主特写套话（霸总笔法） | 懒洋洋的笑、好看的眉眼、深邃的眼睛、玩味的笑意、意味深长、从容得近乎慵懒、修长的手指 | 删；主导方只写外部动作与语言，不作外貌特写 |
| 话本比喻 | 像藤蔓一样挂、软成一滩泥水 | 紧紧贴挂、像被抽去了骨头一般 |
| 现代科学词 | 多巴胺、荷尔蒙、神经、电击 | 体感白描 |
| 现代泛称 | 这一方天地、卧房之中、器具、造物 | 这间客房；具体名词 |
| 本土度量 | 尺、寸 | 按身体或世界观量制（「比手指略长」） |
| 生理套话 | 泛白、咬唇见血、心跳如鼓、喉头滚动、指节收紧、掐进掌心、身子绷紧、倒吸冷气 | 从当前场景取物取声 |
| 高潮套话 | 堆积到顶峰、意识融化、意识吞没、最后一丝清明 | 肉体抽搐、汁液外溢、下肢失控的具体动作 |

**总原则**：从当前场景取物取声（烛芯、炭盆、门缝的光、衣料摩擦），写具体而不通用的动作；感官直白、有肉体实感；语感分寸按创作规范文件的基准质地（基准偏译制体者，宁可略生硬，不可太顺滑）。

## 六、常见翻车点

1. **玩法糊成过场**——「换了好几个姿势」一句带过。对策：序列逐项落文，审查逐项核对。
2. **中式艳情词混进句中间**——最难扫。对策：交底列辞藻清单，派单写进硬红线，成文后逐条 grep 扫（主代理直接跑）。
3. **收尾点破关系反转**——把「她逾越了分寸」直接说破。对策：写她不自知，留白。
4. **发情写成分析式条理**——大段心理复盘、人生履历式自白。对策：受害／受制者声口须破碎、直觉，不作论证。
5. **本土度量与器物**——尺、寸、算盘之类。对策：按创作规范文件的量制与器物名。
6. **药水「泛着微光」**——易读成魔法辉光。对策：删，或改为火光下的反光一类自然解释。
7. **生理套话流水线**——任何情绪配同一个体表信号。对策：先做减法，能删就删，留白优先。
8. **男主特写套话（霸总笔法）**——「懒洋洋的笑」「深邃的眼眸」「玩味的笑意」是网文男主特写。对策：主导方只写外部动作与语言，外貌特写一律删。

## 七、三方接口

- **交底时**（《大纲生成》任一档）：玩法序列逐条编号写进段大纲；不成伤／禁忌两条硬边与辞藻纪律写进「红线对照表」的题材红线行；收尾的关系性落点写进本段载荷。
- **派单时**（《文章撰写》）：玩法序列逐项落文的要求写进【本段任务】；辞藻禁用清单写进【硬红线】。
- **审查时**（《文章循环》）：本文第五节辞藻表与第二节铁律并入各线「本段重点」——逻辑线核对序列逐项／不成伤／禁忌逐字／知情边界／世界观口径；文风线逐处扫辞藻表；AI 腔线按《小说助手》reference·常见AI文风判病灶。序列缺项、禁忌违反按红线处置。
- **语感基准**：派单时附创作规范文件指定的情色基准章作白描基准。

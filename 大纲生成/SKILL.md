# 大纲生成（交底闸门）

创作流水线四步：**生成管演什么、为什么这么演；大纲循环管这份大纲结构上可不可靠；文章撰写管怎么演；文章循环管演得对不对。** 本技能是第一步——把作者的意图摊在明面上，确认没读岔，落成一份可供派单的执行规格；不派单、不写正文。

**为什么要有这道闸门**：照意图直接写正文，最容易在理解层翻车——意图读窄了、读岔了，或替作者补了他没想的东西；等正文出来再发现，返工最贵。复述把「理解」摊在明面上，让作者用最低的成本拦住最贵的错误。

## 一、两档（同一份模板，两种进法）

|  | 手动档 | 自动档 |
|---|---|---|
| 触发 | 作者给出台词／动作骨架／方向意图，或点名「先说说你怎么理解」 | 作者只给一句方向，说「自动写」「你自己推」「直接落档」 |
| 事件栏 | 一步一个能指认，条数多 | 可切宽：两句并一句、条数少、覆盖面宽 |
| 其余栏位 | 作者给 | 助手推，落档标「推定」 |
| 流程 | 先复述 → 作者校验 → 落档 | 直接落档 → 作者看完再下令 |

两档产物是同一种段大纲——**栏位一个不多一个不少，水位一样详细**。自动档不是「简版」，是「助手代笔版」：省的是作者口述那道工序，不是规格的密度。作者在自动档落档上改粗为细、补上台词，即成手动档定稿，无需换格式、无需重写。

## 二、手动档流程

### 1. 收意图

把作者的输入分三类记下：

- **台词**：**圣旨资格只有两个来源**——①作者明确标注「一字不改／照录」；②该角色正由作者执（实演引导输入）。凡具其一，零改动。**未标注的台词只是大意，允许润色**（措辞交写作助手）；默认按「大意、可润色」处理，作者点名标注或亲自执角才升格。
- **动作骨架**：A→B→C 的先后。
- **方向意图**：只给意图（「这段从拘谨到忘形」）。

### 2. 可选：派探索子代理

只在复杂段用（人物多、背景重、需考据时）：人物反应拿不准 → 扮演助手试演；利害账算不清 → 理性助手分析；背景、时间线、设定有无冲突 → 理性助手考据。**只派探索，不派审查**——派单照《小说助手》reference·助手派遣，简单段跳过此步。

### 3. 复述理解 ＋ 落档（同轮完成）

**复述三件事，缺一不可**，在聊天里给作者看：

- **情节走一遍**：谁在哪、先做什么、后做什么、停在哪。事实层，不掺解释。
- **想表现的内容**：这一段要落的东西——分几层、各层落点在哪。
- **请作者裁定的疑点**：**只提两类**——①作者没明说、而**不选就无法落笔**的（硬性冲突、绕不开的分歧）；②作者意图**内部确有冲突**、必须他拍板的。除此之外一律不提：凡作者未提、又能靠留白绕开的，不得牵出，更不得反问「要不要写某条线」——那等于替他延剧情。作者给的是边界，不是待办清单。

同时把结构化版本写入段大纲文件（模板见第四节）。若作者只要看理解、暂不落档，则只出聊天里的复述。

### 4. 待作者校验

作者修正则改档；确认即定稿。作者要求结构核验（或段落复杂值得核验）→ 走《大纲循环》；直接开演 → 交《文章撰写》。

## 三、自动档流程

1. **直接落档**：按同一份模板写段大纲——事件栏可切宽，其余栏位由助手推出的**一律标「推定」**；待裁项与作者台词写「无」（自动档不设问、不请示——拿不准的助手自己拍，拍完落进「已定设定」并标推定）。
2. **落档即停**：落完在聊天里报一句——这段从哪到哪、事件几条、推定几处，不评自己推得好不好；**不拟标题、不开正文、不派单、不请示下一步**，作者看完再下令。
3. **作者不吭声＝默认；要改就地改**，改完自然成为定稿——文件只有一份，不存在「升格」这个动作。作者明确给的原话与要求不标推定。要结构核验 → 《大纲循环》。

## 四、段大纲模板

**必备四项**（前三项对应复述的三件事）；其余按需增补，不必凑满；空栏写「无」，不写「待补」。

| 节 | 必备 | 写什么 |
|---|---|---|
| 定位 | ✔ | 一句话：这段是什么、在整章里处于什么位置 |
| 场景与推进 | ✔ | 事件链，编号列（什么算一条事件见下方定义） |
| 本段载荷 | ✔ | 想表现的内容，编号列：分几层、各层落点。这条最忌空泛——写不出具体落点，说明这段还没想清，回去再想，别用漂亮话填 |
| 红线对照表 | ✔ | 本段成文后验货要查哪些红线（见第五节）。**照填，不许省**——缺它这份大纲就是半成品 |
| 反应与弧线 | | 逐句反应表、情绪弧线、称呼体系（演化刻度按创作规范文件） |
| 落笔要点 | | 写法硬约束（不写惊愕、原理不解释、篇幅给谁……） |
| 已定设定 | | 作者已裁定的设定与走向；自动档的推定落这里、逐条标「推定」 |
| 作者台词 | | 作者原句照录，不擅改原意；标明哪些具圣旨资格（「一字不改」标注／作者执角），其余允许润色 |
| 知情边界 | | 谁该知道什么、不该知道什么 |
| 待裁项 | | **仅**第二节·3 的两类；无则写「无」（自动档恒写「无」） |

**什么算一条事件**：可指认的**行为与事实**。手动档一步一条（引路／随行／被拦／改道，各算一条）；自动档可切宽（「领他穿过侧廊，被守卫拦下，一句托词挡回，转入内庭」并作一条）。**评价、因果、心理、预告、演出理由不是事件，不入此栏**——它们不是被禁的写法，是根本不属于这一栏的东西。自检法：删掉某一句，若剧情线并不缺一环，这句就是废话。

## 五、红线对照表

大纲末尾另立「红线对照表」一节：**这一段成文之后，验货要对照哪些红线**。逐段照抄行头、逐段填「本段重点」——它是验货材料，写得越具体，后面审得越准。

| 红线行 | 何时适用 | 本段重点（逐段填） |
|---|---|---|
| **设定红线**：OOC／时间线／逻辑自洽／称谓与设定一致／度量物象 | 恒适用 | 只从本段「落笔要点」「已定设定」提炼（例：「某角色的分寸不得写成主动盘算」），不得新增作者未定的走向要求 |
| **知情边界** | 恒适用 | 本段谁知道什么的特殊账（如底牌是否亮过头） |
| **圣旨台词** | 本段有作者台词／作者执角时 | 列出句子，标圣旨资格来源 |
| **文风用词红线**：语域分层／现代词与网络语／题材辞藻表（按创作规范文件） | 恒适用 | 本段高危词域（例：「某两层语域的对话区分」） |
| **AI 腔红线**：九类病灶（尺子见《小说助手》reference·常见AI文风） | 恒适用 | 本段高危病灶（例：心理密集段重点防「替人物下判断」） |
| **题材红线**：如情色——不成伤／禁忌逐字／玩法序列逐项（见《小说助手》reference·情色场景） | 本段为该题材主干时 | 序列、禁忌、收尾落点逐项 |

> **对照表只回答「这段要查什么」，不定义「派谁查」**——派遣口径（几线、谁审、何时审、豁免怎么记）在《小说助手》reference·助手派遣审查拓扑里，统一一次，不在大纲里逐份重复。

## 六、落档规则

- **路径与命名**：`故事大纲/00x-00y-zzz.md`——`00x` 章序、`00y` 段序、`zzz` 段名；目录不存在则创建。章序沿用《文章撰写》开章的章号。
- **一段一档，新建不覆盖**：每段一份新文件；改稿就地改同一份，段历史天然保留。
- **段大纲不进章节文件**——章节文件永远只放正文。

## 七、红线（生成阶段）

1. **复述不是改稿**：只讲理解，不动笔写正文。
2. **分清「作者说的」与「我推的」**：作者原话是规格；推论一律标「推定」，请作者裁，不得混进规格当既定。
3. **台词照录，不擅改原意**：措辞优化交写作助手——但圣旨资格以第二节·1 的两类来源为准，有资格的零改动。
4. **不扩写走向，也不替他设问**：作者的意图是边界，不替他延长剧情、补他没想到的转折；能留白绕开的一律不牵出，不拿「他没提的事」反问。
5. **作者裁定项标「审执行分寸，不审方向」**：已拍板的落档注明，供后续审查遵守。
6. **不擅自碰封存暗线**：封存项（清单见创作规范文件）启用与否由作者定，交底阶段不得主动牵出。
7. **事件栏只放事件**；空栏写「无」，不解释、不铺垫。
8. **红线对照表不可省**；不自创栏位（增栏即两档同增）。
9. **不拟标题、不开正文、不落章节档**。

## 八、接口

- **生成 →（《大纲循环》结构核验，按需）→ 《文章撰写》实演 → 《文章循环》验货**。
- 段大纲是《文章撰写》派单「必读文件」清单里的一项（随附件送达）。
- 这一段若是情色主干，玩法序列与辞藻纪律见《小说助手》reference·情色场景，并入对应栏位与红线行。

## 九、适用边界

- **适合**：对话密集、心理密集、人物少的室内戏——理解层最易出岔，交底收益最大。
- **不适合**：大场面群戏、多线并进、时间跨度大的结构梳理——先做跨角色、跨阶段的时序梳理，再把其中一格拆成一段来交底。

# 文章循环（正文验货回修）

正文的毛病分两种：**红线违反**（OOC、知情边界、称呼串层、辞藻表命中、圣旨被改、题材红线）——pass/fail 硬判定，必须闭合；**风格建议**（质地、声口、节奏）——是材料不是判决，采纳与否主代理自判。本循环把前者清零、把后者筛一遍，改到干净。

**对标 coding 的评审循环**：有明确的终点态（段-ready／章-ready）、轮次上限、产出落盘——不是「审到感觉没问题」。

## 一、什么时候用

- **段后按需**：段落档作者点名「审一下这段」，或段大纲红线对照表「本段重点」标了高危项。
- **章末全量（强制）**：收尾成章前，三线全量质检——段级省的这里补齐，这是章级质量闸门。
- **复审**：回修落库后验证闭合。
- **不用**：大纲没演成正文（结构核验走《大纲循环》）；作者明确豁免的线（豁免落章状态，永不重审）。

## 二、审查拓扑（三线）

**同材料、不同尺子，可并发。** 审什么由《大纲生成》的红线对照表逐段给出——表中标「适用」的行进入对应线，「本段重点」随单附上；本节定怎么派、几线、什么口径。

| 线 | 派谁 | 尺子（审查细则） |
|---|---|---|
| **逻辑线** | 理性助手 | 本技能 `reference/逻辑线审查.md`；对照表「设定红线／知情边界／题材红线」行由此线担 |
| **文风线** | 写作助手 | 本技能 `reference/文风线审查.md`（叠项目语感基准＋《小说助手》reference·常见小说文风） |
| **AI 腔线** | 写作助手（**独立派单**，不与文风线合并） | 《小说助手》reference·常见AI文风（九类病灶）＋段落统计；词表 grep 由主代理先行跑完随单附上 |

**选择性深度**（派遣经济学）：

- **逻辑线每段必派**——硬红线集中地。
- 文风线／AI 腔线按红线对照表「本段重点」是否命中该线决定派否；作者主动豁免任何线均有效。
- **豁免必须落章状态文件**（段号、豁免了哪条线、作者原话），不活在对话里——会话一断，豁免丢了就是违约重审。
- **章末全量三线强制**（作者明确豁免的线除外）——段级可以省，章级质量闸门不省。

## 三、循环（一轮的完整结构）

1. **机械前置（主代理，不派子代理）**：词表 grep（生理套话／现代词／套路词／题材辞藻表）、称谓表核对、段落统计——结果作为材料随派单附上。
2. **派单**：按红线对照表＋选择性深度，照《小说助手》reference·助手派遣协议（五要素、三铁律、首诊不夹私货）。
3. **汇总解析**：按返回契约两级拆开——红线项逐条**必须处置**（改正文，或列给作者裁定）；建议项主代理自判，不许照单全收（尤其 AI 腔线：短句、寡言、上位者的冷硬，看着像病灶，可能正是骨相）。
4. **回修**：采纳的修改落正文；**圣旨台词零改动**（报告对其的润色建议一律不采纳，逐句比对，有改动即打回）。
5. **复审**：红线项的回修**重派对应线快查**（只查该项是否闭合）；建议项的回修主代理逐句比对。
6. **章状态记录**：轮次、红线处置、豁免、放行结论——审查报告与判定不进章节文件。

## 四、终止条件

**段-ready**（同时满足）：

- 红线违反＝0，或全部已处置（已改／作者已裁定）；
- 本轮回修条目复审全部闭合；
- 豁免均已落章状态。

**章-ready**（在段-ready 基础上追加）：

- 本章每段均段-ready；
- 章末三线全量质检通过（作者豁免的线除外）；
- 作者放行收尾 → 交《文章撰写》成章。

**轮次与震荡**：段级回修循环上限 **3 轮**；同一问题震荡 ≥3 轮 → 停下，把分歧两端列给作者拍板——真值在作者，不在循环。子代理失败／返回不合格：重派一次（修措辞不重发）→ 仍失败则主代理手工等效审查并标注「手工审查」（见《小说助手》reference·助手派遣失败政策）。

## 五、产出

| 产出 | 落点 |
|---|---|
| 修订后的正文 | 章节草稿档（就地改，不另存审查版） |
| 审查与回修记录（轮次／红线处置／豁免／放行结论） | 章状态文件 |
| 章-ready 放行信号 | 交《文章撰写》收尾成章 |

## 六、红线

1. **报告是材料，不是判决**——但红线不是材料，是闸门。
2. 圣旨台词零改动；未标圣旨的润色建议也须经主代理裁定，不自动落库。
3. 审查报告、质检注、回修痕迹**永不进章节文件**。
4. 不审大纲（走《大纲循环》）；不越权改走向——走向类分歧列两端请作者拍板。
5. 豁免不落章状态＝白豁免。

## 执行检查清单

- [ ] 机械前置已跑（grep／称谓核对／统计），结果随单附上
- [ ] 三线按对照表与选择性深度派单；逻辑线每段必派；章末三线全量
- [ ] 首诊派单无私货；复审只带条目不带解读（铁律照《小说助手》reference·助手派遣）
- [ ] 红线／建议两级拆开；红线全部闭合或已提请作者
- [ ] 回修后已复审；圣旨台词逐句比对零改动
- [ ] 终止条件核对：段-ready／章-ready 各条满足
- [ ] 轮次／处置／豁免已落章状态；审查材料未进章节文件
